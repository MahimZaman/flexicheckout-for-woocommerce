# FlexiCheckout

Custom WooCommerce checkout builder using Elementor.

## Installation and use

Place the `flexicheckout-for-woocommerce` directory in `wp-content/plugins/` and activate **FlexiCheckout** from the WordPress Plugins screen.

Built for WooCommerce and Elementor. Several checkout components and the checkout template are empty in this development snapshot.
